## 📌 Resumen del Proyecto
Este proyecto aborda el diseño arquitectónico inicial para una plataforma e-commerce (Marketplace) orientada al rubro de mascotas. Se define una estructura basada en **tres capas** (Presentación, Lógica de Negocio y Datos) e integración con **sistemas externos** (Pasarela de Pago, ERP y Servicio de Envío).
