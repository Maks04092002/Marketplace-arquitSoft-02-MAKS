# Actores del Sistema

## Actores Humanos
| Actor | ¿Qué necesita realizar? |
| :--- | :--- |
| **Cliente** | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar sus pedidos. |
| **Seller** | Ofrecer productos, registrar productos, actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas. |
| **Administrador** | Administrar la plataforma y gestionar vendedores registrados. |

## Sistemas Externos
| Sistema Externo | ¿Qué necesita realizar? |
| :--- | :--- |
| **Pasarela de pago** | Procesar pagos con tarjetas y medios digitales. |
| **Servicio de envío** | Gestionar información de entrega y rastreo de pedidos. |
| **Servicio de Facturación** | Generar comprobantes electrónicos de pago. |
| **ERP** | Proporcionar información centralizada de productos y stock. |
